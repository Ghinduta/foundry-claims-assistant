# Quiz rules

How to add questions to [quiz.md](quiz.md) after a session.

- **Start from what we built, then go wider.** First the decisions and errors from the session, then the neighbouring exam topics in the same skill area: the alternatives we didn't pick, limits and tiers, failure modes, and "which one would you choose when…". Not only our claims example.
- **One question per idea.** Before adding one, search quiz.md for a question with the same meaning. If there is one, sharpen it instead of adding a near-duplicate.
- **Only key questions.** Each one should test something the exam is likely to ask, not trivia about our code.
- **Exam style.** Mostly a short scenario with one best answer (A–D). Some matching, ordering or "name the three things". Use real Azure names (roles, properties, SDK classes).
- **Answers are hidden** in `<details>`. 1–3 sentences: the answer, why, and why the tempting wrong option is wrong.
- **Verified facts only.** Check Microsoft Learn or the SDK when unsure. Mark preview features as "(preview)".
- **Append a dated section per session**, number questions continuously, and update the score line at the end.
- Weak spots from the study log in [progress.md](progress.md) get a follow-up question from a different angle.
